# Саундпад: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Опциональный модуль «Саундпад» в десктоп-клиенте: 5 слотов для своих звуков (≤10 с), импорт с обрезкой по волне и предпрослушиванием, проигрыш в эфир и локально.

**Architecture:** Встроенный модуль за трейтом `Module`, выключен по умолчанию. Ядро (`core`) получает `Pad` — независимые очереди инстансов для эфира и мониторинга с voice stealing; `TxPipeline` подмешивает их после VAD, мимо мьюта микрофона. Клиент (`client`) хранит импорт/хранение/UI: дровер внизу экрана, диалог обрезки, предпрослушивание через временный вывод звука.

**Tech Stack:** Rust (edition 2024), egui 0.37, cpal, symphonia 0.5, rubato, rfd, hound.

**Spec:** `docs/superpowers/specs/2026-11-05-soundpad.md`

## Global Constraints

- Коммиты — одна строка по-русски (стиль: «Ядро: …», «Клиент: …»).
- Проверка всего — `cargo test --workspace` зелёный; клиент собирается `cargo build -p voiceon`.
- Все звуковые буферы модуля — 48 кГц моно f32 (`core::mixer::SAMPLE_RATE`).
- В `core` новых зависимостей нет (`pad.rs` — только std). Новые зависимости только в `client`.
- Изменения в `core` только добавляющие: `ffi` (Android) и `--bot` должны собираться и работать как раньше (это покрывает `cargo test --workspace`).
- UI — в стиле `client/src/ui/theme.rs` / `widgets.rs` (Palette, `widgets::round_button`, `widgets::toggle`, `widgets::volume_slider`, `widgets::icon_button`), подписи по-русски, иконки `egui_phosphor::regular`.
- Значения из спеки: 5 слотов, клип ≤ 10 с, ≤ 4 инстансов на слот, источник ≤ 180 с.

## Review Focus

Спека молчит об этих входах; каждый прибит тестом в своей задаче:

1. Невалидный/неподдерживаемый файл на импорте → понятная ошибка в диалоге, слот не меняется (тест `decode_garbage_errors`, задача 4).
2. Источник длиннее 3 минут → отказ с сообщением, без выделения гигабайт памяти (тест `decode_too_long_errors`, задача 4).
3. Тихий/немой кусок при нормализации → без inf/NaN и усиления тишины (тест `normalize_silent_clip_no_panic`, задача 4).
4. WAV слота удалён/испорчен при запуске → слот молча очищается, приложение живо (тест `load_skips_missing_and_garbage_slots`, задача 7).
5. Конфиг старой версии без секции `[soundpad]` → дефолты: модуль выключен, громкость 1.0 (тест `old_config_without_soundpad_parses_with_defaults`, задача 3).

- [ ] **Шаг 3: реализовать инъекцию в `finish_frame`**

В `TxPipeline` поле `pad_buf: [f32; FRAME_SAMPLES]`. В `finish_frame`, не меняя существующий `voice_send = self.frame_open && !muted && connected`:
```rust

  pub const MAX_CLIP_SECS: f32 = 10.0;
  const MAX_SOURCE_SECS: f32 = 180.0;
  const TARGET_RMS: f32 = 0.1;
  const MAX_GAIN: f32 = 4.0;
  const PEAK_CEILING: f32 = 0.95;
  const FADE_MS: usize = 5;

  /// Декод файла в 48 кГц моно; дольше MAX_SOURCE_SECS — Err.
  pub fn decode(path: &std::path::Path) -> Result<Vec<f32>, String>;

  pub fn peaks(samples: &[f32], buckets: usize) -> Vec<(f32, f32)>;
  /// Обрезка [start,end) сек (кламп к MAX_CLIP_SECS), фейды FADE_MS, нормализация.
  pub fn prepare_clip(source: &[f32], start: f32, end: f32) -> Vec<f32>;
  pub fn save_wav(samples: &[f32], path: &std::path::Path) -> Result<(), String>;
  pub fn load_wav(path: &std::path::Path) -> Result<Vec<f32>, String>;
  /// dirs::data_dir()/voiceon/sounds
  pub fn sounds_dir() -> Option<std::path::PathBuf>;
  ```

- [ ] **Шаг 1: падающие тесты**

В `import.rs`:
- `trim_clamps_to_ten_seconds`: источник 20 с константы 0.5, `prepare_clip(_, 5.0, 20.0)` → длина `10.0 * 48000` (±2 сэмпла).
- `fades_silence_endpoints`: первый и последний сэмплы результата ≈ 0.0.
- `normalize_hits_target_rms`: синус с RMS 0.01 → после `prepare_clip` RMS ≈ `TARGET_RMS` (±10%).
- `normalize_silent_clip_no_panic`: нули → результат из нулей, без inf/NaN (проверить `iter().all(|s| s.is_finite())`).
- `wav_roundtrip`: `save_wav` → `load_wav` → длина совпадает, значения в пределах квантизации i16 (±0.0001).
- `decode_wav_file`: hound пишет 44.1 кГц стерео WAV 1 с → `decode` → ~48 000 сэмплов (±1%).
- `decode_garbage_errors`: файл из случайных байт → `Err`.
- `decode_too_long_errors`: hound пишет 181 с тишины 48 кГц моно → `Err` (в сообщении про длину).

- [ ] **Шаг 2: запустить, убедиться в падении**

- [ ] **Шаг 3: реализовать `import.rs`**

`decode`: `symphonia::default::get_probe()` + `get_codecs()`, первый трек; пакеты → f32, миксдаун усреднением каналов; ресемпл `rubato::SincFixedIn` (1 канал), если частота ≠ 48 000; отказ при превышении `MAX_SOURCE_SECS`. `prepare_clip`: кламп диапазона (`0 ≤ start < end ≤ длительность`, `end - start ≤ MAX_CLIP_SECS`, минимум 0.1 с), линейные фейды по краям, затем `normalize`: gain = `TARGET_RMS / rms`, ограничен `MAX_GAIN` и `PEAK_CEILING / peak`. WAV — hound, 48 кГц моно i16.

- [ ] **Шаг 1: импорт в `Soundpad`**

Открытие: `rfd::FileDialog` (фильтр mp3/wav/ogg/flac) → `TrimState`; `import::decode` — в рабочем потоке (`std::thread` + `std::sync::mpsc`), пока `busy` — спиннер в диалоге; `Err` → `error` в диалоге (красный бокс как `error_box`). `import_into`: `prepare_clip(source, start, end)` → `save_wav` в `slot_{i}.wav` → обновить `slots[i]`, `cfg.soundpad.slots`, `cfg.save()`.

- [ ] **Шаг 2: диалог и волна**

`trim_dialog`: `egui::Window` (заголовок — имя файла). Волна — `peaks(source, 512)` через `ui.painter()` (вертикальные линии min..max), поверх полупрозрачная заливка выбранного диапазона. Ручки начала/конца — драг-зоны (`Sense::drag`), клампы: `0 ≤ start < end ≤ длительность`, `end - start ≤ MAX_CLIP_SECS`, минимум 0.1 с; под ними метки времени. Кнопки: «Прослушать» (`Preview::play` диапазона, громкость `cfg.soundpad.volume`), «Отмена», «Добавить» (→ `import_into`, ошибка — в диалог). Рендерится из `VoiceApp::ui` поверх текущего экрана, когда `soundpad.trim.is_some()`; на время диалога `ctx.request_repaint_after(100ms)`.

1. «+» → выбор mp3 → волна видна, ручки таскаются, дальше 10 с не разводятся.
2. «Прослушать» играет выбранный кусок (и на логине, и в звонке).
3. «Добавить» → слот заполнен; перезапуск приложения — слот на месте.
