# Изменения

## 0.2.1

- Linux: после автообновления приложение снова перезапускается само.

## 0.2.0

- Новый интерфейс: тёмная и светлая тема по системе, иконки, аватары участников,
  индикатор «говорит», круглые кнопки микрофона, звука и отключения.
- Настройки на отдельном экране: устройства, порог голосовой активации на живом
  индикаторе, выключатель шумодава.
- Автообновление: клиент сам скачивает новую версию с GitHub, проверяет подпись
  и перезапускается, когда нет звонка.
- Переподключение больше не оставляет «призрака» в списке участников.
- Адрес сервера можно вставлять как ссылку (`https://…`).
- Журнал событий `voiceon.log` рядом с конфигом — пригодится для разбора обрывов.
- Разовые сбои буфера звука больше не показываются как ошибка.

## 0.1.0

- Первая версия: relay-сервер, клиент для Windows и Linux.
